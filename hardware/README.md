# hardware/ — نسخه KiCad برد V2

- `kicad/esp07_4relay.kicad_pro` + `kicad/esp07_4relay.kicad_pcb` — KiCad **7.x** به بالا.
- `pcb_preview.png` — پیش‌نمای رندر.

## وضعیت طراحی (صادقانه)

✅ چیدمان قطعات مطابق عکس برد واقعی (چیدمان میلی‌متری از روی عکس‌های سازنده)
✅ نت‌لیست کامل روی پدها + نام‌گذاری کانال‌ها مطابق سیلک (CH1..CH4 ↔ RELAY1..4 ↔ GPIO4/5/12/13)
✅ فوتپرینت رله = پدپترن **رسمی KiCad** برای SANYOU SRD سری Form C
✅ روتر شبه‌اولیه: درخت تغذیه (۱۲V←جک←دیود←باک، SW، ۵V، ۳٫۳V)، باس ۱۲V بوبین‌ها، ۴ مسیر GPIO←درایورها، UART/USB، زنجیره RF
✅ زون GND در دو لایه

⚠️ قبل از سفارش ساخت (چک‌لیست):
1. فوتپرینت‌های سفارشی (`*_hack`، RXB6/FS1000A/… ) را با کتابخانه KiCad هم‌تراز کنید و جک DC-005 / ماژول‌های RF را با دیتاشیت فوتپرینت واقعی‌تان چک کنید.
2. airwireهای باقی‌مانده (پول‌آپ‌های ماژول R13–R16، اتورست Q5، خازن‌های دیکوپل) را روتر کنید یا از freerouting استفاده کنید.
3. ترتیب پین ترمینال‌ها (NC از بالا→پایین) فرضی است — روی نمونه اولیه با مالتی‌متر چک شود.
4. زون‌ها را Refill کنید (B) و DRC اجرا کنید؛ برای تراک برق شهر خزش ≥ 6mm لازم است.
5. Gerber: File → Fabrication Outputs → Gerbers + Drill Files.

## بازتولید از کد

```bash
python3 ../tools/gen_kicad.py   # خروجی را در همین پوشه بازتولید می‌کند
```

موقعیت‌ها و نت‌ها همه در `tools/gen_kicad.py` مستندند — اگر پین‌مپی یا قطعه‌ای را تغییر دادید، همان فایل را ویرایش و دوباره تولید کنید (فرمت KiCad 7 / version 20221018 مطابق KiCad 8-10 هم باز می‌شود).
