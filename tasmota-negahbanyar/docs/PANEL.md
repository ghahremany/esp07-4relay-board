# راهنمای تصویری پنل مدیریت «نگهبان‌یار × Tasmota»

این صفحه ظاهر و جریان کاری چهار صفحهٔ اصلی پنل را نشان می‌دهد.
عکس‌ها رندر **دقیقِ خودِ کد** درایور (`addons/xdrv_150_neghbanyar.ino`) هستند — یعنی عیناً
همان چیزی که بعد از فلش روی برد در `http://<IP>/ngh...` می‌بینید.

> فایل‌های HTML متناظر هر عکس (همین پوشه: `preview_0X_*.html`) را می‌توانید بدون هیچ
> سخت‌افزاری در مرورگر باز کنید و ظاهر/متن را قبل از کامپایل بررسی و ویرایش کنید.

## ۱) صفحهٔ راه‌اندازی — `/ngh/setup`

<img src="screenshots/screenshot_01_setup.png" width="414" alt="setup">

فقط یک‌بار (تا زمانی که کلید TOTP ذخیره نشده) باز است:

- **کلید پیشنهادی Base32** روی خود دستگاه ساخته می‌شود؛ راه امن‌تر: `tools/gen_secret.py`
- **کد QR واقعی آفلاین**: کتابخانهٔ QR داخل فلش اجرا می‌شود — همان را با گوگل‌اوتنتیکیتور اسکن کنید
- هر ویرایش در فیلد Base32، QR همان لحظه بازکشیده می‌شود
- «ذخیره کلید» → کلید در LittleFS از دستگاه قفل می‌شود و صفحه برای همیشه دیگر باز نمی‌شود

## ۲) صفحهٔ ورود — `/ngh/login`

<img src="screenshots/screenshot_02_login.png" width="414" alt="login">

- کد ۶ رقمی فعلی Google Authenticator (TOTP: SHA1/۳۰ثانیه/۶رقم، سازگار با RFC 6238)
- پنجرهٔ پذیرش ±۱ قاب (تا ۹۰ ثانیه تلرانس ساعت)
- ۵ خطای پشت سر → **قفل ۱۸۰ ثانیه‌ای** (پیام «⏳ قفل امنیتی»)
- ورود موفق → کوکی نشست امضاشده ۱۰ دقیقه‌ای (HttpOnly + SameSite=Strict)

## ۳) داشبورد — `/ngh`

<img src="screenshots/screenshot_03_dashboard.png" width="414" alt="dashboard">

- **۴ کارت رله** با نام فارسی دلخواه (در تصویر: چراغ ورودی روشن است) — سوویچ لمسی = POST به API
- نگاشت GPIO روی هر ردیف چاپ شده (RELAY1..4 ← GPIO4/5/12/13)
- کارت وضعیت: IP، تعداد رله‌ها، ساعت UTC، آپ‌تایم
- خط وضعیت Interlock و وبهوک
- دکمه‌ها: تنظیمات، صفحهٔ اصلی Tasmota، خروج

## ۴) تنظیمات نگهبان‌یار — `/ngh/config`

<img src="screenshots/screenshot_04_config.png" width="414" alt="config">

- هویت سامانه: نام مجتمع، **Building ID** (bid — همان که اپ ملازم آن است)، وبهوک رویداد رله، Interlock
- **نام‌های فارسی ۴ رله** که در داشبورد و برای اپ (`op=state`) برمی‌گردد
- **کلید API اپ (۱۲ hex)**: امضای HMAC-SHA1 با این کلید ← قرارداد در [API.md](API.md)
- دکمهٔ **چرخش کلید API** — کلاینت‌های قبلی از کار می‌افتند، TOTP ادمین دست‌نخورده می‌ماند

## جریان کامل یک‌نگاه

```
boot → setup (Base32 + QR، آفلاین) → ذخیره کلید در فلش
     → login (کد گوگل‌اوتنتیکیتور) → داشبورد (سوویچ رله‌ها)
     → config (نام‌ها/وبهوک/Interlock/چرخش کلید API)
     → اپ نگهبان‌یار با api_key به /ngh/api وصل می‌شود
```

همهٔ صفحات RTL، بدون نیاز به اینترنت (فونت فارسی سیستم گوشی)، واکنش‌گرا روی صفحهٔ
موبایل با عرض حداکثر ۴۶۰ پیکسل ساخته شده‌اند — دقیقاً برای استفادهٔ نگهبان از گوشی.
