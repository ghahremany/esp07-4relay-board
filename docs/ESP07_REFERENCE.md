# مرجع کامل ماژول ESP-07 (برای توسعه فریمور و سخت‌افزار این برد)

> جمع‌آوری‌شده برای پروژه برد ۴ رله ECA-22665 — همه آنچه هنگام کدنویسی نیاز دارید.
> منابع: دیتاشیت Ai-Thinker ESP-07 V1.1، مستندات Espressif ESP8266EX، و برد واقعی.

---

## ۱. مشخصات کلی ماژول

| مورد | مقدار |
|---|---|
| چیپ | Espressif **ESP8266EX** (پردازنده Tensilica L106 ‏۳۲بیتی @ 80MHz، قابل اورکلاک به 160MHz) |
| فلش | SPI Flash خارجی — پیش‌فرض **8Mbit = 1MB** (نسخه ESP-07**S** جدیدتر: 4MB)|
| Wi-Fi | 802.11 b/g/n ‏۲٫۴GHz — STA / SoftAP / STA+AP — رمزنگاری WPA/WPA2 (WEP/TKIP/AES) |
| آنتن | **دو نوع:** آنتن سرامیکی داخلی + کانکتور **U.FL/IPEX** برای آنتن خارجی (برای استفاده از U.FL باید خازن کوپل روی ماژول جابه‌جا شود) |
| توان خروجی | تا +20dBm در 802.11b |
| ابعاد | **21.2 × 16.0 × 3.0mm** (با شیلد فلزی) |
| پکیج | SMD-16 — ۱۶ پد کاستلیتد (نیم‌سوراخ) دو طرفه |
| گام پد‌ها | **2.0mm** (نه 2.54!) — اندازه هر پد ۰٫۹ × ۱٫۷mm |
| تغذیه | **3.0 تا 3.6V** (تایپیک 3.3V) — ورودی‌های GPIO **هرگز 5V تلران نیستند** |
| جریان | متوسط ~80mA، پیک در TX تا ~300–430mA → رگولاتور 3.3V باید حداقل **500mA** جریان دهد |
| دمای کاری | -40 تا +125 درجه |
| شیلد | دارد (روی شیلد: WiFi ESP8266MOD + نشان FCC/CE) |
| ماژول‌های مشابه | ESP-07S (فقط U.FL، فلش 4MB) — پایه‌ای سازگار ✅ |

## ۲. جدول پایه‌ها (۱۶ پایه — نمای بالا، آنتن سرامیکی بالا)

کتگوری سمت راست و چپ مطابق سیلک روی برد ما هم هست:

| شماره پد | نام | کاربرد / ملاحظه |
|---|---|---|
| 1 | RST | ریست فعال-LOW؛ پول‌آپ ۱۰k روی برد وجود دارد |
| 2 | ADC (TOUT) | ورودی آنالوگ **۰ تا ۱٫۰V** (۱۰ بیتی) — بیشتر از ۱V ممنوع |
| 3 | EN / CH_PD | فعال‌سازی چیپ؛ باید HIGH باشد (پول‌آپ روی برد) |
| 4 | GPIO16 | بیدارباش Deep-Sleep (به RST وصل کنید) — **وقفه خارجی ندارد**، PWM سخت‌افزاری هم نه؛ هنگام بوت پالس HIGH می‌دهد |
| 5 | GPIO14 | HSPI_CLK — **وقفه خارجی دارد** → در این برد: **گیرنده RF433** |
| 6 | GPIO12 | HSPI_MISO — در این برد: **RELAY3** |
| 7 | GPIO13 | HSPI_MOSI — در این برد: **RELAY4** |
| 8 | 3V3 | تغذیه ۳٫۳V |
| 9 | GND | زمین |
| 10 | GPIO15 | HSPI_CS — **در بوت باید LOW باشد** (پول‌داون روی خود ماژول/برد) — روی این برد فقط روی پد بریک‌اوت آمده |
| 11 | GPIO2 | TXD1 — **در بوت باید HIGH باشد** (پول‌آپ روی خود ماژول) — LED آبی روی ماژول (LOW = روشن) |
| 12 | GPIO0 | ورود به حالت فلش زدن (LOW هنگام بوت) — کلید FLASH روی برد — پول‌آپ دارد |
| 13 | GPIO4 | **RELAY1** روی این برد (سیلک D04) |
| 14 | GPIO5 | **RELAY2** روی این برد (سیلک D05) |
| 15 | RXD (RXD0) | سریال پروگرام ← TXD چیپ CH340G |
| 16 | TXD (TXD0) | سریال پروگرام → RXD چیپ CH340G — هنگام بوت روی آن لاگ چاپ می‌شود |

> ⚠️ پایه‌های مورد استفاده فلش داخلی (SDxx) روی ESP-07 به بیرون نیامده‌اند — برخلاف ESP-01 که GPIO9/GPIO10 دارد.

## ۳. قوانین بوت (حیاتی برای کدنویسی)

| GPIO | شرط بوت نرمال از فلش | نکته |
|---|---|---|
| GPIO15 | LOW | اگر HIGH باشد بوت نمی‌شود — هرگز pull-up خارجی نزنید |
| GPIO0 | HIGH | LOW = ورود به UART Bootloader برای پروگرام |
| GPIO2 | HIGH | وگرنه بوت نمی‌شود (خازن/مقاومت به GND هم نزنید) |

- رله‌ها روی **۴/۵/۱۲/۱۳** هستند و همه این پایه‌ها در بوت آزاد می‌توانند هر سطحی بگیرند؛ بنابراین در `setup()` فریمور **قبل از هر چیز خروجی رله‌ها را LOW** کنید (پالس چند ده میلی‌ثانیه هنگام ریست طبیعی است).
- **RXD/TXD** در بوت برای لاگ بوت‌رام ESP استفاده می‌شود — دستگاهی که اینجا وصل است نباید هنگام ریست داده بفرستد.

## ۴. مصرف جریان و مدیریت انرژی

| حالت | جریان تغذیه ۳٫۳V |
|---|---|
| TX (802.11b, +17dBm) | ~170mA (پیک تا ~300mA) |
| TX (802.11g/n) | 120–140mA |
| RX | 50–56mA |
| Modem-Sleep | ~15mA |
| Light-Sleep | ~0.9mA |
| **Deep-Sleep** | **~10–20µA** (بیدارشدن: اتصال GPIO16→RST یا ریست خارجی) |
| Power-down | < 5µA (EN=LOW) |

در این برد رگولاتور ۳٫۳V از ریل ۵V باک تغذیه می‌شود؛ حد مفید ریل ۵V برای چهار رله هم‌زمان ≈ ۰٫۱۵A (@12V مبدل) باقی می‌گذارد.

## ۵. نگاشت پین‌های این برد (سیلک سازنده — تأییدشده)

| عملکرد | GPIO | سیلک برد | وضعیت |
|---|---|---|---|
| RELAY1 | **4** | D04 | سانسور درایور BC817 + مقاومت بیس ۱k + LED کانال |
| RELAY2 | **5** | D05 | همان‌طور |
| RELAY3 | **12** | D12 | همان‌طور |
| RELAY4 | **13** | D13 | همان‌طور |
| RF433 RX DATA ← | **14** | — (در V2) | وقفه خارجی ✔ (لازمه rc-switch) |
| RF433 TX DATA → | **16** | — (در V2) | خروجی ساده از طریق شیفتر 2N7002 |
| سریال پروگرام | RXD/TXD | — | CH340G + کریستال ۱۲MHz + اتو-ریست |
| کلید RESET | RST | — | کلید بالایی لبه چپ |
| کلید FLASH | GPIO0 | — | کلید پایینی لبه چپ |
| ADC | TOUT/A0 | ADC | فقط تا ۱V — برای سنسور آنالوگ آزاد |
| بریک‌اوت اضافه | 2, 15 | D2, D15 | روی پدها — با قوانین بوت ملاحظه شود |

## ۶. نکات کدنویسی (Arduino Core)

```cpp
const uint8_t RELAY[4] = {4, 5, 12, 13};  // برد ECA-22665 — فعال HIGH
void setup() {
  for (auto p : RELAY) { pinMode(p, OUTPUT); digitalWrite(p, LOW); } // اولِ اول!
}
```

- **شماره‌گذاری در Arduino**: از شماره GPIO مستقیم استفاده کنید (این برد `` D0 ``-های Wemos ندارد؛ DX روی سیلک = شماره GPIO مستقیم).
- **WiFi قبل از millis()**: مقداردهی اولیه WiFi به‌صورت خودکار؛ برای کاهش مصرف `WiFi.mode(WIFI_OFF)` تا زمان نیاز.
- **rc-switch** روی GPIO14: `mySwitch.enableReceive(14)` — GPIO16 در rc-switch برای TX نیاز به وقفه ندارد.
- **Deep-sleep**: `ESP.deepSleep(us)` + سیم‌بندی GPIO16→RST (روی این برد به‌سادگی با سیم از پدهای بریک‌اوت).
- **PWM**: `analogWrite()` روی همه GPIOها جز GPIO16.
- **I2C نرم‌افزاری**: پیش‌فرض SDA=4, SCL=5 است — روی این برد رله‌ها هستند! با `Wire.begin(sda,scl)` روی پایه‌های آزاد (مثلاً 0/2، با احتیاط بوت) تغییر دهید.
- **فلش ۱MB** یعنی OTA فقط با طرح partition بزرگ (مثلاً 1MB FS:64KB) و فریمور < ~480KB قابل انجام است.
- تنظیمات Arduino IDE برای این ماژول: Board: *Generic ESP8266 Module* — Flash Size: *1MB (FS:64KB OTA:~470KB)* — Upload speed 460800.

## ۷. ملاحظات سخت‌افزاری برد میزبان

- پدها ۲mm هستند؛ برای هدر استاندارد ۲٫۵۴mm باید از آداپtor استفاده کرد.
- ماژول روی برد میزبان **مستقیم لحیم** شده (بدون سوکت) — تعویض ماژول دشوار است.
- کانکتور U.FL کنار لبه پایین-راست ماژول است؛ برای آنتن خارجی Wi-Fi باید خازن ۰Ωِ کوپل روی خود ماژول جابه‌جا شود.
- LED آبی کوچک سمت چپ پایین ماژول = روی GPIO2 است (فعال LOW).
- فاصله ماژول از سلف باک ≈ ۸mm — مناسب؛ ولی آنتن سرامیکی را از بدنه فلزی ماژول دور نگه دارید.
